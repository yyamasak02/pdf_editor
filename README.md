# PDF編集ツール

ブラウザだけで動くPDF編集ツールです。サーバーへのアップロードは一切行わず、すべての処理はお使いのブラウザ内(JavaScript)で完結します。

TypeScriptで実装し、`dist/app.js` にビルドしたものを `index.html` が読み込む構成です(pdf.js / fabric.js / pdf-lib も含めて1ファイルにバンドル済みなので、ビルド後はネット接続なしでも動作します)。

## 使い方(ビルド不要・すぐ使う)

1. `index.html` をブラウザ(Chrome / Edge / Firefoxなど)で直接開いてください。
   - ローカルファイルとして `file://` で開いても動作します。
   - `dist/` にビルド済みファイルを同梱しているため、Node.jsのインストールは不要です。
2. 「PDFを開く」からPDFファイルを選択します。
3. 左側のツールパネルで編集内容を選びます。
   - **選択**: 配置した要素の選択・移動・リサイズ・削除(矢印キーで1pxずつ、Shift+矢印キーで10pxずつ移動)
   - **テキスト**: クリックした位置にテキストボックスを追加(左右のハンドルで幅のみ変更、文字サイズは変わりません)
   - **画像**: 画像ファイルを選んでページに配置(ドラッグで移動・リサイズ可)
   - **四角形 / 楕円**: ドラッグして図形を描画
   - **ペン/署名**: フリーハンドで描画(手書き署名にも使えます)
   - 色・塗りつぶし・線の太さ・文字サイズは選択中のツールまたは選択中のオブジェクトに適用されます
   - オブジェクトを選択すると、サイドバーの色・塗りつぶし・文字サイズがそのオブジェクトの現在値に自動で切り替わります
4. PDFにフォーム項目(AcroForm)が含まれている場合、「フォーム項目」パネルから値を入力できます。「保存時にフォームを確定(編集不可にする)」にチェックを入れると、保存時に入力内容が固定されます。
5. 「PDFを保存」をクリックすると、編集結果を反映した新しいPDFファイルがダウンロードされます(元のファイルは変更されません)。

## 再編集(このツールで保存したPDFを、あとでまた編集する)

「PDFを保存」で書き出したファイルには、見た目のための加工とは別に、

- 加工前の原本(そのままのPDF)
- 各ページの注釈データ(テキスト/画像/図形などの編集状態)

が添付ファイルとして一緒に埋め込まれます。このファイルを再び「PDFを開く」で読み込むと、このツールが自動的にそれを検出し、保存時点の編集状態をそのまま復元します(どの要素も引き続き選択・移動・削除・編集が可能です)。保存を何度繰り返しても、加工前の原本を土台にして注釈を描き直すだけなので、注釈が二重に焼き込まれることはありません。

ブラウザの開発者ツールのConsoleに `このツールで保存済みのPDFを検出したため、前回の編集内容を復元しました。` と出れば復元成功のサインです。

この仕組み上、保存のたびにファイルサイズは「元のPDF + 原本の複製 + 編集状態」の分だけ増えます(通常の用途では問題にならない程度です)。

## 開発者向け: ソースからビルドする

```sh
npm install
npm run build      # dist/app.js と dist/pdf.worker.min.js を生成
npm run watch       # ソース変更を監視して自動リビルド
npm run typecheck   # 型チェックのみ実行(ビルドしない)
```

ソースは `src/` 以下のTypeScriptです。型安全性のため以下の構成にしています。

- `src/types.ts` … アプリ全体で使う型定義
- `src/state.ts` … アプリの状態(ページ、fabricキャンバス等)
- `src/dom.ts` … DOM要素の取得(存在しなければ例外を投げる)
- `src/pdfView.ts` … PDF読み込み・ページ表示・ズーム
- `src/canvasTools.ts` … 描画ツール・選択・矢印キー移動などfabric.js周り
- `src/formFields.ts` … AcroFormの読み込みと反映
- `src/exportPdf.ts` … PDF書き出し(pdf-lib)
- `src/persistence.ts` … 再編集用の状態埋め込み/復元

## できること

- テキスト・画像・図形(四角形/楕円)の追加
- フリーハンド描画による手書き署名の追加
- PDFフォーム項目(テキスト欄・チェックボックス・ラジオボタン・ドロップダウン)への入力と確定(flatten)
- 複数PDFの結合と順番の並べ替え(ヘッダーの「PDFを結合」)
- 複数ページの個別編集、ページ送り、表示倍率の変更
- このツールで保存したPDFを再度開いての再編集(上記「再編集」参照)

## 制限事項

- 配置した要素の回転には対応していません。
- テキストは常にHelvetica系フォントで書き出されます(日本語など非ラテン文字は現状未対応で、保存時にエラーになります)。
- ページ単位の追加・削除・分割には対応していません(ファイル単位の結合・並べ替えは「PDFを結合」で可能)。
- 結合時、各PDFのフォーム項目と、このツールで保存したPDFの再編集データは引き継がれません(見た目のみ結合されます)。
- 再編集用のデータを埋め込むため、保存のたびにファイルサイズが増えます。

## AIからの編集・CLI

画面操作なしで、JSONの指示だけでPDFを編集できます(CLI・ブラウザ用API)。詳しくは [docs/AI.md](docs/AI.md) を参照してください。
